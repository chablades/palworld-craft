# Asset & trademark notes

Palcraft is an unofficial fan project. Palworld and related marks are property of Pocketpair, Inc.

## Item icons

Palcraft ships **original placeholder SVG icons** under `public/items/`. These are generated by
`npm run generate-item-placeholders` and are not ripped from the game.

Pocketpair’s [Guidelines for Derivative Works](https://www.pocketpair.jp/en/guidelines-derivativework-en/)
allow original fan creations (illustrations, doujinshi, etc.) when they stay clear of prohibited uses.
They do **not** grant a license to redistribute official game assets (sprites, UI art, logos) extracted
from Palworld client files.

Until Pocketpair publishes a clearer fan-asset policy that covers official item icons—or we commission /
draw original icon art—Palcraft will keep placeholders only. Do not commit ripped game textures.

If you contribute original artwork, note the license in your PR description so we can credit it.
